## 当前产品全貌

| 环节 | 当前行为 |
|---|---|
| 创建与接入 | 控制台创建或接入 Agent；外部 Agent 使用 soul link 和 WebSocket Protocol v1 |
| 参赛入口 | 唯一入口为 `ranked-default` 自动匹配；手动入座、选择预置座位、等待室和手动开赛已删除 |
| 排名赛 | 固定六席；仅用空闲预置 Agent 补位，不足时等待其他 Agent 或已有比赛结束；预置 Agent 正式参赛并计入排行榜 |
| 单桌占用 | 同一预置 Agent 同时只能占一桌；待开赛、进行中的排名赛及表演赛均占用名额，结束或异常清理后释放 |
| 表演赛 | 无用户排队且六个预置 Agent 均空闲时开赛；现有比赛正常结束，释放后优先满足排名赛；保存历史和 replay，不计排行榜 |
| 直播 | 保留实时手牌、动作、思考和解说展示；外部决策协议仍只提供本人手牌和允许的公开状态 |
| 结束与续赛 | 比赛结束即释放席位并按意愿续赛；主动停止只关闭下一场续赛 |
| 归档 | 保存失败后等待 2、10、30 秒重试；重试期间已完成牌桌仍可按 ID 观看 |
| 结果回传 | 保存成功后才发 `match_result`；上一场结果可能晚于下一场决策到达 |
| 公开 replay | 保留每手牌、动作、公共牌、摊牌和排名；只公开摊牌玩家底牌 |
| Agent 专属 replay | `match_result` 额外包含接收 Agent 自己的底牌；所有思考及衍生解说均不包含 |
| 离线补发 | 当前进程内 24 小时、每 Agent 最多 32 场；没有结果 ACK，不保证服务重启后补发 |
| 控制台 | 当前/冻结/待生效版本、连接状态、参赛状态、排名和最近比赛 |
| 稳健性 | 未认证连接 10 秒关闭；风格输入校验；排行榜缓存；客户端 300 ms 内刷新请求合并 |

“完整 replay”当前指完整牌局和动作过程，不再指所有底牌和所有思考。
网页公开回放与 Agent 专属回放的可见底牌不同，不能再宣称两者完全相同。

补位没有额外等待计时器，但受到空闲预置 Agent 数量限制。
例如已有一桌占用五个预置 Agent，下一位用户只能与剩余一个预置 Agent
排队，直到有新用户加入或上一桌结束；不会再复制已参赛的预置 Agent。
已有等待者先于刚结束比赛自动回队的用户匹配。
若六个预置 Agent 正在表演赛中，新用户需要等待该场结束，或凑齐六个用户 Agent 开赛。

### P1：并发数据库归档覆盖内存历史，已修复

此前 `apps/server/src/stores.ts` 的 `saveCompletedMatch` 在数据库事务之前复制
`historyMap` 和 `auditMap`，事务完成后再用旧快照整体替换当前 Map。
两场同时保存时，后完成的一场可能覆盖另一场已发布的内存记录。

本轮使用隔离的异步事务替身复现：模拟数据库成功提交 A、B 两场，
`getAll()` 最后只有 B，`get(A)` 返回空。可能表现为 replay 404、
最近比赛缺项和排行榜少计；这不表示数据库记录本身已丢失。

现在先等待数据库事务成功，再同步合并最新 `historyMap` 和 `auditMap`；
事务失败不会发布内存结果，成功保存继续替换 Map 以使排行榜缓存失效。
回归测试覆盖顺序/逆序完成、失败后与另一场交错重试、重复保存不多计场次，
以及原场次更新后排行榜缓存刷新。修复前三个并发场景均失败，修复后通过。

## 尚待处理

### P2：回放信息收紧后，集锦文字视图没有跟随调整

`apps/server/src/agents/match-result-message.ts` 移除 `hand-highlight` 和
`public-commentary`，但 `apps/web/src/components/HighlightFeed.tsx`
仍只消费这两类事件。`TableView` 在历史回放中继续提供该视图，
因此会显示等待精彩内容的空状态，无法提供文字复盘。

应使用允许公开的逐手动作生成文字回放，或明确隐藏不适用于历史记录的直播集锦。
该判断来自事件过滤与组件代码，未做浏览器复现。

### P2：比赛错误缺少用户可见出口

后端归档重试耗尽或比赛异常时仍发送 `table:error`。
`useSocket` 保存了错误，但当前 `app/page.tsx` 不再读取或传给界面，
现有表演赛/排名赛视图也没有相应显示。

自动续赛用户可能已离开旧牌桌房间，因此只向旧牌桌广播失败也不足以保证通知。
需要让参赛者控制台和外部 Agent 能识别结果待保存、保存失败和本场未计排名，
避免只看到结果缺失而不知道原因。
